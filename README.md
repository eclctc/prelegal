# prelegal
A platform for drafting common legal agreements

- `templates/` – Common Paper legal templates (CC BY 4.0), listed in `catalog.json`
- `frontend/` – Next.js Mutual NDA creator; see [frontend/README.md](frontend/README.md) to run it
## Status

🚧 **In progress.** This project is under active development and is expected to be complete in one week (by 2026-10-10). Details on setup and usage will be added as the project nears completion.
